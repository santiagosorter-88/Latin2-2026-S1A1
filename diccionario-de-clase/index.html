Diccionario de clase

317 palabras — el vocabulario de las frases en latín ya vistas en clase (Ovidio, Cicerón, Plinio el Joven, Higino)

Cómo se arma: cada vez que se suman frases nuevas a la base de clase, este glosario se vuelve a generar con el vocabulario que aparece en ellas. Las palabras marcadas con macrones y clasificadas por declinación/conjugación siguen la Base de datos de vocabulario de la cátedra; el resto tiene traducción propia.
